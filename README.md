# finance-portfolio
Профессиональный профиль финансового аналитика — учебный проект HTML/CSS для курса AI-навыки финансиста.

## Проектные кейсы

### [Контроль просроченной дебиторской задолженности](appendices/receivables-bpmn.html)

Проект регламента с BPMN-маршрутом, ролями, контрольными точками и правилами эскалации. Данные обезличены; документ предназначен для демонстрации методики.

[Открыть графическое приложение](https://kks374038-commits.github.io/finance-portfolio/appendices/receivables-bpmn.html)

### [Криптопортфель](dashboards/crypto-portfolio/)

Демонстрационный кабинет с ручным вводом и CSV-загрузкой операций, учётом комиссий, прироста активов и разграничением ролей администратора и пользователя.

[Открыть демо](https://kks374038-commits.github.io/finance-portfolio/dashboards/crypto-portfolio/)

Все данные в демо обезличены и не содержат сведений о контрагентах или рабочих компаниях.
