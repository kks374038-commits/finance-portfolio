# Портфель — криптоактивы

[Открыть демонстрацию](https://kks374038-commits.github.io/finance-portfolio/dashboards/crypto-portfolio/)

Тёмный интерфейс с янтарными акцентами: 10 популярных активов, график баланса и отдельный график ручных начислений, периоды 7/30/90 дней, история операций, ручной ввод и CSV, демонстрационное переключение кабинетов администратора и пользователя.

Это публичная браузерная демонстрация на синтетических данных. Изменения сохраняются только в localStorage этого браузера. Роли переключаются без входа и не защищают реальные данные. Выписки, реальные балансы, email клиентов, токены и содержимое закрытой базы в репозитории отсутствуют. API рабочего кабинета не вызывается. Реальные переводы и биржевые сделки не выполняются.

Список BTC, ETH, USDT, BNB, XRP, USDC, SOL, DOGE, TRX, ADA — подборка популярных активов, а не текущий рейтинг по капитализации. Котировки не загружаются. График показывает количество активов и отдельно начисления администратора, без подмены пополнений доходностью.

Исходники демо — в source/. Node.js 22.13+; npm install; npm run build; npm test. Каталог сборки source/dist-demo. Десять проверок графика, изоляции активов, периода и сторно. В закрытой серверной версии дополнительно проверены 26 сценариев доступа и операций.

Рабочая версия с серверной проверкой ролей, персональными портфелями и постоянной базой развёрнута отдельно и имеет закрытый доступ.
