# Портфель — доступ по секретной ссылке

Статический клиент GitHub Pages. Без выданного владельцем секретного ключа данные не запрашиваются. Ключ находится во фрагменте ссылки и передаётся только в заголовке запроса защищённому API. Полные ссылки и ключи не размещаются в репозитории. Сервер определяет роль и портфель; подмена роли в интерфейсе не даёт прав записи.

Одна ссылка разрешает операции администратора в одном портфеле, другая — только просмотр. Владелец через вход ChatGPT может приостановить обе ссылки. Сервер проверяет срок действия и SHA-256 ключа.

10 популярных криптоактивов, ручной прирост, комиссии на вход/выход, учётный обмен с ручным курсом и комиссией 0,08% по умолчанию. Полное списание и чистое зачисление показываются до записи. Комиссии хранятся отдельными строками; связанные операции и сторно атомарны. Реальные платежи и сделки не выполняются.

Предлагаемый тариф обмена сопоставлен с базовым спотовым тарифом Bybit Non-VIP 0,1%, а не с любым VIP-продуктом. On-chain вход у Bybit бесплатен; вывод зависит от актива и сети, ориентир вводится вручную. Источник: https://www.bybit.com/en/help-center/article/Bybit-Fees-You-Need-to-Know (26.11.2026).

Реальная база находится на отдельном сервере; балансы, операции, email, ключи и содержимое базы в GitHub не сохраняются. Опубликована оболочка, исходники и тесты. Node.js 22.13+; в source/: npm install, npm run build, npm test. Всего 65 автоматических проверок. Скрипты транзакций и ограничений доступа в source/lib/ предназначены для серверной версии, не загружаются как база в браузер.
