## Воспроизводимый прогон

```bash
python scripts/build_demo.py
python -m unittest discover -s tests -v
```

Зафиксированный локальный результат: **20 тестов успешно**, 100 касс: 61 matched, 24 attention, 15 blocked; 3 проекта переводов, все `NOT_EXECUTED`.

## Приёмка пилота

Предлагается начать с 10 позиций, затем расширить до 30 и 100. В выборке должны быть ручной файл, API, банк, кошелёк, несколько валют, позднее событие, возврат и незавершённый перевод.

Gate расширения: пять последовательных дневных циклов с контролем всех ожидаемых источников, доказуемой сверкой и успешными негативными сценариями. Изменения состава раскрываются отдельно. Задержка одного источника не скрывается уменьшением ожидаемого количества касс.

Если gate не пройден, владелец процесса утверждает причины, корректирующие действия, исполнителя и дату повторной проверки. Масштабирование откладывается. Контроль реальных денег продолжается по действующему утверждённому порядку.
